# Lista de Tareas - Actividad Semana 3: Cloud Computing

Aplicación web simple (Flask) con base de datos PostgreSQL, desplegada en Render
como ejemplo de un servicio **PaaS** en un modelo de despliegue de **nube pública**.

## Ejecutar localmente (opcional)
```
pip install -r requirements.txt
python app.py
```

## Despliegue en Render
Este repositorio incluye `render.yaml`, por lo que Render puede crear
automáticamente el servicio web y la base de datos con la opción "Blueprint".
